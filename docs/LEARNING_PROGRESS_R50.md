### [R50-Q01] 개념: `C01_DATA_DIKW` (`LUCKY_GUESS_CONFUSED`)

- **핵심 불변 규칙 (Core Invariant)**: [데이터와 DIKW 피라미드] 데이터(Data): 개별 데이터 자체로는 의미가 미약한 순수한 관찰/측정된 객관적 사실(Fact) / 정보(Information): 데이터를 처리/가공하여 데이터 간의 연관 관계와 맥락(Context)을 부여한 상태 / 지식(Knowledge): 다양한 정보를 구조화/일반화하여 개인의 경험, 규칙, 통찰과 결합한 상태
- **선지 변별 포인트**: • 학습자 선택(2): I(Insight): 데이터를 가공·처리하여 데이터 사이의 관계와 의미를 도출한 결과이다.
• 실제 정답(2): I(Insight): 데이터를 가공·처리하여 데이터 사이의 관계와 의미를 도출한 결과이다.

### [R50-Q22] 개념: `C20_STATISTICAL_INFERENCE` (`KNOWN_UNKNOWN`)
- **오답 원인 요약**: [대칭 개념 혼동 (CONCEPT_SWAP)] 선택하신 'p-value는 1/32이고, 귀무가설을 기각한다....'와 정답 선지 'p-value는 1/16이고, 귀무가설을 기각하지 않는다....' 간의 핵심 개념 속성을 혼동하였습니다.
- **핵심 불변 규칙 (Core Invariant)**: [가설검정과 통계적 추론] 귀무가설(H0, 차이 없음/효과 없음) vs 대립가설(H1, 증명하고자 하는 새로운 가설) / 제1종 오류(alpha): 귀무가설이 참인데 기각할 확률 (유의수준) / 제2종 오류(beta): 귀무가설이 거짓인데 채택할 확률 (검정력 = 1 - beta)
- **선지 변별 포인트**: • 학습자 선택(1): p-value는 1/32이고, 귀무가설을 기각한다.
• 실제 정답(4): p-value는 1/16이고, 귀무가설을 기각하지 않는다.
• 핵심 변별 포인트: p-value 판정: p < alpha 이면 귀무가설 기각(유의미한 차이 있음), p >= alpha 이면 귀무가설 채택(기각 실패)
- **소크라테스 문답 기록**: • [내가 헷갈렸거나 잘못 알고 있던 개념]: 동전 5번 모두 앞면이 나올 확률만 1/32로 계산하고 양측검정(앞면 5번 + 뒷면 5번 = 2/32 = 1/16)을 놓쳤으며, '이상한 일이 많이 발생해 p-value가 유의수준보다 높으면 기존 가설을 기각해야 하는 것 아닌가?'라고 p-value와 유의수준의 의미를 반대로 이해함.
• [소크라테스 문답을 통해 교정된 핵심 개념]: 1) 양측검정이므로 양쪽 극단 확률을 합쳐 p-value = 1/32 + 1/32 = 1/16(0.0625)임. 2) p-value는 '귀무가설이 맞다고 할 때 순전히 우연으로 이런 극단적 결과가 나올 확률'임. 따라서 우연일 확률(p-value)이 유의수준(α=0.05)보다 작아야(p < α) '도저히 우연일 수 없다'고 보아 귀무가설을 기각함. 여기서는 0.0625 > 0.05이므로 귀무가설을 기각하지 않음(4번). 또한 유의수준(α)은 낮을수록(예: 1%) 실수를 허용하지 않는 더 엄격한 검증임.
