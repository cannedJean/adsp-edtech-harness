### 🧠 Phase 2 전역 진단 및 완료된 5대 족집게 클리닉 요약

1. **근본 원인 진단 (Claude Opus 5.5)**:
   - 누적 오답의 **71.4%**가 지식을 아예 모르는 것이 아니라, **용어 대칭 반전(`INVERSION_OF_TERMS`, 42.9%)**과 **부정형 발문 미인지(`MISREAD_NEGATIVE`, 28.6%)**에서 발생함.
   - **메타인지 보정도**: Brier Score `0.2289`, ECE `0.0847` (**균형 보정형 Well-Calibrated** — 본인이 아는 것과 헷갈리는 것을 매우 정확히 인지함).
2. **완료한 5대 핵심 취약점 족집게 클리닉**:
   - **[클리닉 1] 제2과목 분석 마스터플랜 우선순위 4사분면**:
     - 제3구역(시급성 高, 난이도 低) 무조건 1순위 / 시급성 기준(`3 → 1 → 4 → 2`) vs 난이도 기준(`3 → 4 → 1 → 2`)
     - 시각화 자료: [`docs/assets/priority_matrix.png`](assets/priority_matrix.png)
   - **[클리닉 2] 제2과목 분석 조직 구조 3유형**:
     - 집중 구조(독립 전담조직, **현업과 이원화·중복 우려**) vs 기능 구조(전담조직 X, 각 부서 자체 수행, **전사적 관점 부족**) vs 분산 구조(전담 인력 현업 파견, 신속 적용, 역할 분담 필요)
   - **[클리닉 3] 제3과목 회귀분석 결정계수($R^2$) vs 수정 결정계수($Adj\text{-}R^2$)**:
     - 독립변수 추가 시 $R^2$는 무조건 증가/유지되나, $Adj\text{-}R^2$는 불필요한 변수 추가 시 자유도 페널티로 감소 가능 (항상 $Adj\text{-}R^2 \le R^2$).
   - **[클리닉 4] 제3과목 시계열 AR(p) vs MA(q) 및 PACF의 통계적 원리**:
     - $AR(p)$는 중간 시점들의 간접 매개 효과를 통제(제거)해야 직접 차수가 보이므로 **편자기상관함수(PACF)가 시차 $p+1$에서 절단**됨 (`AR → PACF 절단`, `MA → ACF 절단`).
   - **[클리닉 5] 제3과목 표본추출법 대조**:
     - 층화추출 = **"층·내·동 / 간·이"** (집단 내 동질, 집단 간 이질)
     - 군집추출 = **"군·내·이 / 간·동"** (집단 내 이질, 집단 간 동질)
   - **[추가 수리 시각화]**: 지수분포(Exponential) vs 포아송분포 그래프 ([`docs/assets/exponential_dist.png`](assets/exponential_dist.png))

## 2. 🎯 새로운 환경에서 시작할 때: 어디서부터 시작해야 하는가?

제50회(1~50번)와 제49회(1~50번), 그리고 Phase 2 전역 진단 및 5대 취약점 클리닉까지 모두 완료된 상태입니다.  
**새 세션에서는 아래 두 가지 코스 중 하나를 선택하여 즉시 시작**하면 됩니다:

### 👉 코스 A (가장 추천): Phase 3 최신 기출 트렌드 신유형(OOD) 백신 훈련
- **목적**: 제46~50회 최신 기출 개념 표류(`SMOTE`, `Elastic Net`, `ESD`, `GMM`, `ANOVA/회귀 결과표 역산` 등)를 반영한 신유형 5문항을 풀고 소거법 프로토콜을 훈련합니다.
- **실행 명령어**:
  ```powershell
  python -m adsp_harness.cli phase3 --count 5
  ```

### 👉 코스 B: 제48회 기출문제 실전 풀이 (`R48-Q01`부터 시작)
- **목적**: 앞서 교정한 개념과 발문 극성 체크 프로토콜을 적용하여 제48회 기출(1번~50번)에서 60점 이상 & 전 과목 과락 면제를 달성합니다.
- **실행 명령어**:
  ```powershell
  python -m adsp_harness.cli show --round 48 --qno 1
  ```

## 3. 💻 새로운 PC / 환경에서 세팅 및 재개하는 방법

### Step 1. 저장소 클론 (또는 최신 상태 Pull)
```powershell
git clone <저장소_URL>
cd ADsP
# 이미 클론된 환경이라면:
git pull origin main
```

### Step 2. 에이전트(Antigravity) 실행 및 첫 프롬프트 입력
새 환경에서 Antigravity 세션을 열고 아래 문장 중 하나를 그대로 입력하시면 에이전트가 `GEMINI.md`와 `docs/SESSION_HANDOFF.md`, 그리고 `learner_state.db`를 자동으로 읽고 바로 이어서 진행합니다:

> **프롬프트 예시 1 (Phase 3 신유형 훈련부터 시작할 때)**:  
> `"docs/SESSION_HANDOFF.md 확인해줘. 이어서 Phase 3 신유형(OOD) 백신 훈련부터 진행하자."`

> **프롬프트 예시 2 (제48회 기출 1번부터 풀고 싶을 때)**:  
> `"docs/SESSION_HANDOFF.md 확인해줘. 이어서 제48회 기출 1번(R48-Q01)부터 문제 내줘."`
